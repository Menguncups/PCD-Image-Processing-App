Cara memakai

  1. Muat Citra A sebagai citra utama. Operasi juga boleh dipilih lebih dulu; setelah Citra A dimuat, form operasi yang tertunda otomatis terbuka.
  2. Kartu parameter selalu tampil di bawah kartu citra. Sebelum operasi dipilih, kartu berisi petunjuk dan tombol Jalankan nonaktif. Di desktop, sidebar selalu terbuka; di layar sempit, sidebar menjadi laci yang ditutup lewat tombol X.
  3. Pilih operasi pada menu sidebar. Bila operasi membutuhkan dua citra, kartu Citra B muncul meski belum diisi, bahkan sebelum Citra A dimuat; form parameter tetap terbuka dan tampilan menggulir ke kartu B. Muat Citra B dengan ukuran yang sama.
  4. Pada Add, Subtract, Multiply, dan Divide, pilih Jenis operan. Citra + Citra memakai Citra B, sedangkan Citra + Skalar hanya memakai Citra A dan satu nilai angka tanpa memeriksa Citra B. Hasil aritmetika selalu di-clip ke rentang 0-255.
  5. Isi parameter. Rumus operasi tampil di panel parameter dan dirender dengan KaTeX. Operasi ringan non-Geometric langsung memperbarui pratinjau saat penggeser digeser. Operasi berat dan seluruh operasi Geometric memakai tombol Jalankan tanpa pratinjau otomatis. Panel parameter tetap terbuka setelah hasil muncul.
  6. Periksa hasil pada kartu Hasil. Label menunjukkan dimensi, jumlah kanal, dan skala hasil terhadap Citra A. Klik Tutup di kanan atas kepala kartu untuk membuang hasil. Kartu Hasil tidak menampilkan tombol Bandingkan atau Unduh.
    7. {% if aplikasi.TAMPILKAN_TERAPKAN %}
  7. Klik Terapkan untuk memakai hasil pada Citra A, atau Tutup untuk membatalkannya. Save dan Save As pada menu File tetap menyimpan Citra A.
    8. {% else %}
  8. Tombol Terapkan sedang disembunyikan pada konfigurasi ini. Save dan Save As pada menu File tetap menyimpan Citra A, bukan hasil operasi.
    9. {% endif %}
  9. Reset mengembalikan Citra A ke citra awal. Undo tersedia untuk membatalkan penerapan terakhir bila fitur Terapkan diaktifkan.

Teknologi

Flask untuk server web, NumPy dan OpenCV untuk pengolahan citra, SciPy untuk operasi morfologi dan pengisian rongga, KaTeX 0.19.1 yang disimpan lokal untuk rumus, serta HTML, CSS, dan JavaScript tanpa kerangka kerja tambahan untuk antarmuka.
